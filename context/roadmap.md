# Antigravity Masterclass Roadmap

This roadmap structures the topics from the README into a logical learning progression, moving from core philosophy to advanced AI-agent architectures.

## Phase 1: Foundation & Philosophy (The Setup)
- [ ] **Project Structure**: "Big" build structure (`/apps`, `/packages`, `/context`)
- [ ] **Agent Rules**: Non-negotiables (No unapproved libs, verify everything)
- [ ] **The "Context" Folder**: The Brain of the operation (`project_goals.md`)
- [ ] **Context Priming**: Using `.agrules` to force context ingestion

## Phase 2: Core Workflows (The Process)
- [ ] **The Artifact Protocol**: Plan Mode (The Architect) vs. Fast Mode (The Intern)
- [ ] **Advanced Context Management**: Using `@` mentions to direct focus
- [ ] **Skill Definitions**: `SKILL.md` files as Standard Operating Procedures
- [ ] **Model Switching**: The Relay Strategy (Flash for grunt work, Opus/Sonnet for logic)

## Phase 3: Advanced Development Techniques (The "Cracked" Prompts)
- [ ] **The "Senior Dev" Self-Roast**: Forcing the agent to critique and iterate
- [ ] **The "UI Thief"**: Pixel-perfect design cloning from screenshots
- [ ] **The "Docs Injection"**: Manual RAG for new/niche APIs
- [ ] **The "Pseudo-Code Architect"**: Logic-first approach for massive features
- [ ] **The "Context Wipe"**: Clearing pollution with a fresh chat
- [ ] **The "Mock Data Factory"**: Generating massive datasets for stress testing

## Phase 4: Verification & QA (Trust but Verify)
- [ ] **Test-Driven Chat**: Writing tests *before* implementation
- [ ] **Vision Verification**: Forcing visual audits via screenshots
- [ ] **The "Console Log Sherlock"**: Automated log analysis and debugging
- [ ] **Automated Browser Testing**: Defining "Click Paths" for the agent

## Phase 5: God Mode (Advanced Integration)
- [ ] **MCP Integration**: Bridging the agent to infrastructure (Logs, DB)
- [ ] **Local LLMs**: Using Ollama/Cline for offline/free coding
- [ ] **Asset Generation**: Using "Nano Banana" for instant assets
